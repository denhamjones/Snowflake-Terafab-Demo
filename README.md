# Terafab Command Center · a Snowflake demo concept

A single-page, interactive demo concept that shows how a fab team could run yield, cost and tool-health decisions on governed data in Snowflake. Views: Overview, Watch Model (7-step walkthrough with FEL / LPP EUV source toggle), Yield planner, Cost / Yield, Wafer map (3D, WebGL) and a natural-language Assistant with a "View SQL" panel.

The site is one self-contained `index.html` with no external requests, so it runs from any static host, including GitHub Pages.

**Synthetic data, built to show the method.** All figures, lots, tools, product names and IDs are fictional and do not represent real Terafab or xAI operations.

**Marks:** Terafab and xAI names and marks appear for internal and call use only. Do not publish or distribute this site publicly.
